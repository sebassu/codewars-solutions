# SQL Basics: Simple WITH

For this challenge you need to create a `SELECT` statement that will use an `IN` to
check whether a department has had a sale with a price over **98.00 dollars**.

### `departments` table schema

- `id`
- `name`

### `sales` table schema

- `id`
- `department_id`
- `name`
- `price`
- `card_name`
- `card_number`
- `transaction_date`

### Resultant table schema

- `id`
- `name`
