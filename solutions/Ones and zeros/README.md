# Ones and zeros

Given an array of ones and zeroes, convert the equivalent binary value to an integer.
For example: `[0, 0, 0, 1]` is treated as `0001` which is the binary representation of
`1`.

### Examples:

- [0, 0, 0, 1] → 1
- [0, 0, 1, 0] → 2
- [0, 1, 0, 1] → 5
- [1, 0, 0, 1] → 9
- [0, 0, 1, 0] → 2
- [0, 1, 1, 0] → 6
- [1, 1, 1, 1] → 15
- [1, 0, 1, 1] → 11
