# [SQL Basics: Create a FUNCTION](https://www.codewars.com/kata/580fe518cefeff16d00000c0)

For this challenge you need to create a basic "Increment" function, which increments the
age field of the peoples table. The function should be called `increment`: it needs to
take 1 integer and increment that number by 1.

You may query the `people` table while testing, but the query must only contain the
function on your final submit.

**Important:** you must remove all comments when submitting the kata

### `people` table schema

- `id`
- `name`
- `age`

**Note:** Your solution should use PL/SQL.
